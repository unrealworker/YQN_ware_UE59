# GHS 仓库网页版部署

先完整解压压缩包。Windows x64 服务器无需安装 UE、Node.js 或 Python，包内 Runtime 已包含 Python 3.13.3 运行环境及许可证。浏览器用户无需安装任何程序。

## 先在服务器本机验证

双击 `Start-Local.bat`，在本机 Chrome/Edge 打开 `http://127.0.0.1:8800/`。保留服务窗口，关闭或按 Ctrl+C 停止。不要双击 Wasm/index.html。

## 让其他电脑访问

1. 为服务器准备客户端信任的 HTTPS 证书和 PEM 格式私钥。证书 SAN 必须包含实际访问的域名或 IP；使用内网 CA 时，在客户端安装其可信根证书。
2. 将证书放到 `certs/warehouse.crt`，私钥放到 `certs/warehouse.key`，或者修改 `server.json` 中对应路径。
3. 修改 `server.json` 的 `allowed_hosts` 为其他电脑使用的服务器域名/IP，按需修改端口（默认 8800）。域名要通过内网 DNS 解析到服务器。
4. 在服务器防火墙为所需局域网网段放行 TCP 8800，然后双击 `Start-LAN.bat`。
5. 用户在 Chrome/Edge 访问 `https://服务器域名或IP:8800/`。所有客户端应看到有效可信的 HTTPS 连接。

原生 WebGPU 需要安全上下文；普通 `http://局域网IP` 或证书错误页面不能替代以上 HTTPS 配置。服务提供 COOP/COEP/CORP、Brotli、字节范围请求和正确资源类型。配置中的域名是示例，必须替换。不要把 MCP 端口当成网页访问端口。

服务文件全部使用相对路径，可放在任意本地目录。Windows 计划任务可设置“登录时/启动时运行”，程序为此目录 `Runtime\python.exe`，参数为 `-I -B start_server.py`，起始目录为解压目录。也可由现有进程管理器托管相同命令。

## IIS、nginx 或其他系统

仅将 `Wasm/` 作为网站根目录，不要将 Runtime、私钥或整个解压目录公开。`Hosting/` 包含 IIS、nginx 和 Apache 配置参考，未在这三种服务器上实机验收；HTTPS 证书、域名和根目录需替换为目标主机实际值。

Linux/macOS 可安装 Python 3.9+，然后运行 `python3 -I -B start_server.py`；包内 Runtime 仅用于 Windows x64。

默认关卡为 GHS_GlobalWarehouse，含 GHS 加州仓库和 MPR 新泽西仓库。建议使用支持 WebGPU 与 BC 纹理压缩的桌面 Chrome/Edge，首次访问需要下载资源；此包未作为手机兼容版本验收。
