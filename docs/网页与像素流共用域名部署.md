- UE 5.9 原生网页入口：`https://warehouse-sim.iyunquna.com/web/`
- `/web` 自动重定向到带尾斜杠的 `/web/`，保留查询参数。

没有新增域名、证书、DNS、ALB 规则或公网端口。用户明确允许一次短暂断线后，使用原像素流启动器停止并启动服务，加载新增路由。原根页面、访问模式、流送程序及端口配置保持。

## 服务组成

已有 HTTPS ALB 回源到本机 TCP 8080。像素流服务只新增 `/web` 与 `/web/*` 路由，固定转发至 `127.0.0.1:8800`；原根页面、`/health`、会话 API、WebSocket 与 UE 信令保持原处理逻辑。

网页后端使用包内 Python，只监听本机回环地址，服务根目录为 `C:\UEpro\warehouse5_9\Deployment\GHS-Warehouse-Web-UE59-20261117-r2\Wasm`。计划任务 `GHS-Warehouse-Web` 以 `LOCAL SERVICE` 运行，开机启动，失败后每分钟重试，最多 10 次。

公网两个入口均需要原像素流启动器保持运行，因为其 8080 端口负责接收现有 ALB 回源。8800 网页后端独立运行，不创建 UE 串流实例，用户浏览器本地执行 WebAssembly/WebGPU。

只发布 Wasm 网站文件，未暴露 Runtime、私钥、项目源码。代理保留 MIME、Brotli、COOP/COEP/CORP、Range/206，使用固定本机上游，丢弃 Cookie、Authorization 及逐跳头。正常 Service Worker scope 为 `/web/`。
